# Bundled SRD Core Pack

This directory owns Tavern Born's generated SRD 5.1 + SRD 5.2.1 resource pack.

- `provenance.json` pins the official documents, hashes, prescribed attribution, license, and
  transformation notice.
- `dependency-allowlist.json` records untagged support rows that SRD-tagged roots reference, along
  with the owning SRD and official section.
- `data/` and `manifest.json` are generated by `scripts/build-srd-snapshot.mjs`. They are not
  committed or packaged while provenance status is `provenance-review-required`.

Generate a review snapshot from an explicit external 5etools-format checkout:

```text
npm run generate:srd -- --source-root data --upstream-revision <pinned-revision>
```

Verify that a checked snapshot matches the same input:

```text
npm run verify:srd -- --source-root data --upstream-revision <pinned-revision>
```

The generator reads the source root but never writes to it.
